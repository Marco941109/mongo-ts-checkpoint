# Mongo + TypeScript API

API desarrollada con **Node.js, TypeScript y MongoDB** como parte del checkpoint.

## 🚀 Funcionalidades
- CRUD de Users, Trucks, Orders, Locations.
- Autenticación con JWT.
- Validación de modelos antes de insertar en MongoDB.
- Uso de ramas en GitHub para cada dominio.

## ▶️ Ejecutar localmente
```bash
npm install
npm run dev
